Fonts used by the voice window renderer (arona/voice_engine/src/window.py).
Base text uses Segoe UI from Windows; these are fallbacks for glyphs Segoe UI lacks.

NotoColorEmoji.ttf          color emoji (CBDT)        https://github.com/googlefonts/noto-emoji   SIL OFL 1.1
NotoSansJP-Regular/Bold.otf Japanese (kana/kanji)     https://github.com/notofonts/noto-cjk       SIL OFL 1.1
SymbolsNerdFont-Regular.ttf Nerd Font icon glyphs     https://github.com/ryanoasis/nerd-fonts     MIT / OFL
