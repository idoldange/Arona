Aronauti Timer

Trích trực tiếp từ HUD timer trong video.mp4 → vector outline (TrueType), 0-9 + dấu “:”

Bộ ký tự

0123456789:

Ví dụ

02:57
00:00
12:34
09:59

Cách dùng

<style>
@font-face{
  font-family:"Aronauti Timer";
  src:url("aronauti-timer.woff2") format("woff2"),
      url("aronauti-timer.ttf") format("truetype");
  font-display:block;
}
.timer{
  font-family:"Aronauti Timer", monospace;
  font-size:48px;          /* = kích thước đúng trong video 1920x1080 */
  line-height:1;
  color:#e8f4fd;
}
</style>
<div class="timer">02:57</div>

Metrics (units/em = 1000, font-size 48px = đúng pixel trong video)
